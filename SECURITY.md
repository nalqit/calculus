# Security Policy

## Supported Versions

Only the latest version of this library receives security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public issue.

Instead, report it by emailing the project maintainers with:

- A description of the vulnerability
- Steps to reproduce the issue
- Potential impact assessment
- Suggested fix (if any)

We will respond within 7 days and work with you to address the issue.

## Known Limitations (Not Security Issues)

- This library is not designed for untrusted input. Parsing arbitrary user input
  should be done with caution.
- Numerical methods use floating-point arithmetic and may have precision limitations.
- The library operates over real numbers and does not support complex numbers.
